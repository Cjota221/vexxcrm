# 🚀 VARIÁVEIS DE AMBIENTE PARA NETLIFY

## Como Configurar no Netlify

1. Acesse seu site no Netlify Dashboard
2. Vá em **Site settings** → **Environment variables**
3. Clique em **Add a variable**
4. Adicione TODAS as variáveis abaixo

---

## 📋 VARIÁVEIS OBRIGATÓRIAS

### Supabase (Database + Auth)
```
NEXT_PUBLIC_SUPABASE_URL=https://qjjflshqdaapwneeirdq.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=SEU_ANON_KEY_AQUI
SUPABASE_SERVICE_KEY=SEU_SERVICE_KEY_AQUI
```

**Onde encontrar:**
- Acesse https://supabase.com/dashboard
- Selecione seu projeto
- Vá em **Settings** → **API**
- Copie:
  - Project URL → `NEXT_PUBLIC_SUPABASE_URL`
  - anon public → `NEXT_PUBLIC_SUPABASE_ANON_KEY`
  - service_role → `SUPABASE_SERVICE_KEY` ⚠️ **NUNCA exponha esta key no frontend!**

---

### Next.js
```
NEXT_PUBLIC_APP_URL=https://seu-site.netlify.app
```

**Instruções:**
- Após primeiro deploy, atualize com a URL final do Netlify
- Exemplo: `https://vexxcrm.netlify.app`

## 🚀 PASSO A PASSO COMPLETO DO DEPLOY

### 1️⃣ Preparar Repositório
```bash
# Certifique-se de que está tudo commitado
git status

# Se houver mudanças, commite
git add netlify.toml .env.netlify.md
git commit -m "chore: adiciona configuração do Netlify"
git push origin main
```

### 2️⃣ Conectar ao Netlify
1. Acesse https://app.netlify.com
2. Clique em **Add new site** → **Import an existing project**
3. Escolha **GitHub**
4. Selecione o repositório `Cjota221/vexxcrm`
5. Configure:
   - **Branch to deploy:** `main`
   - **Build command:** `npm run build`
   - **Publish directory:** `.next`

### 3️⃣ Configurar Environment Variables
1. Antes de fazer deploy, clique em **Advanced build settings**
2. Clique em **New variable** para cada variável acima
3. Ou pule e configure depois em **Site settings** → **Environment variables**

### 4️⃣ Deploy!
1. Clique em **Deploy site**
2. Aguarde ~3-5 minutos
3. Acesse a URL gerada (exemplo: `vexxcrm.netlify.app`)

### 5️⃣ Pós-Deploy
1. Atualize `NEXT_PUBLIC_APP_URL` com a URL final
2. Configure domínio customizado (opcional):
   - **Site settings** → **Domain management**
   - Adicione `vexxcrm.com` ou outro domínio
3. Habilite HTTPS automático (Netlify faz automaticamente)

## 🔧 TROUBLESHOOTING

### Build Falha com "Module not found"
```bash
# Localmente, teste o build
npm run build

# Se funcionar localmente, limpe cache do Netlify:
# Site settings → Build & deploy → Clear cache and retry deploy
```

### "Failed to load env variables"
- Verifique que TODAS as variáveis obrigatórias estão configuradas
- Variáveis com `NEXT_PUBLIC_` são case-sensitive
- Não use aspas ao configurar no Netlify

### "Supabase Auth Error"
- Verifique que `NEXT_PUBLIC_SUPABASE_URL` e `NEXT_PUBLIC_SUPABASE_ANON_KEY` estão corretos
- Acesse Supabase → **Authentication** → **URL Configuration**
- Adicione a URL do Netlify em **Site URL** e **Redirect URLs**

### Páginas retornam 404
- Verifique que `netlify.toml` está no root do projeto
- O plugin `@netlify/plugin-nextjs` deve estar instalado
